9.1. Server Diagnostic Logs. As is standard practice for any web server, the infrastructure hosting the Web Hub automatically records certain non-identifying technical information for every request made to it, including: truncated or hashed IP address ranges, browser user-agent string, referring URL, requested resource path, HTTP response status code, and request timestamp (collectively, "Server Logs"). Server Logs are not used to build individual user profiles, are not cross-referenced with review submissions, and are not shared with advertising networks.
